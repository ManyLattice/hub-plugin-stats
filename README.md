# hub-plugin-stats

Плагин для [Agents Hub](https://github.com/flagman/agents-hub-core): статистика клонов репозиториев `hub-plugin-*` по GitHub Traffic.

![Статистика](icon.png)

- раз в сутки (и при старте) процесс собирает `traffic/clones` через `gh api` для всех публичных репо владельца с префиксом `hub-plugin-`;
- история копится в `<папка хаба>/stats-plugin/clones.json` (`~/.hub-core/stats-plugin/`) дольше 14 дней GitHub, дубли по дню не плодятся;
- вкладка «Статистика» на странице хаба; в терминале - `python3 main.py report`;
- владелец по умолчанию - аккаунт, под которым вы вошли в `gh`; меняется в `<папка хаба>/stats-plugin/settings.json` (`{"owner": "..."}`).

В счёт клонов входят и ваши установки, ревью-клоны и обновления плагина: цифры - верхняя граница чужих установок. «Уникальных» - за день, их сумма по дням не равна числу людей. Нужен вход `gh auth login` с правом push к репо.

До 1.0.1 данные лежали в `<папка хаба>/stats/` (это папка модуля статистики ядра). При старте плагин переносит оттуда свои `clones.json` и `settings.json`, если в `stats-plugin/` их ещё нет; файлы ядра остаются на месте.

Тесты: `PYTHONPATH=<код хаба>:. python3 -B -m unittest discover -s tests`
